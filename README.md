<h3>$ cat experiencia.txt</h3>

**Full Stack Developer** · Magne Studios · oct 2025 – actualidad · Remoto

Diseño y desarrollo sistemas de gestión a medida de punta a punta, desde el análisis de requerimientos hasta el despliegue en producción.

- Diseñé la arquitectura backend de un sistema de gestión integral de 18 módulos (NestJS, Fastify, PostgreSQL) con una única API para la web y la app móvil, control de acceso por rol (RLS) y auditoría de cada operación. Eliminó la duplicación de lógica entre plataformas y dejó el 100% de las operaciones trazables.
- Desarrollé un ERP con módulos integrados de operaciones y finanzas a partir de 63 requerimientos funcionales. Centralizó información que estaba dispersa en planillas, redujo cerca de un 40% el tiempo de carga administrativa y le dio a la dirección datos en tiempo real.
- Construí un sistema de gestión operativa (órdenes de trabajo, stock, turnos y facturación electrónica) con Next.js, TypeScript y Supabase. Digitalizó el 100% de un circuito que se hacía en papel y automatizó recordatorios a clientes que generan ventas recurrentes.
- Implementé un CRM de pedidos integrado con WhatsApp (Evolution API, n8n) con tablero Kanban configurable. Automatizó la toma de pedidos y redujo cerca de un 50% el tiempo de respuesta al cliente.
- Desarrollé una plataforma multi-tenant que permite operar varias empresas sobre una misma base con datos aislados por cliente. Redujo el costo de incorporar cada cliente nuevo al eliminar los despliegues individuales.
- Automaticé el flujo de entrega con CI/CD (GitHub Actions, Vercel) y Docker, e integré agentes de IA (Claude Code, Cursor) al desarrollo diario. Esto acortó los ciclos de entrega sin resignar control de calidad.
